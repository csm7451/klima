## Reporting a vulnerability

Please use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) to **privately report** a security issue for this repository (tab **Security** → **Report a vulnerability**).

Include steps to reproduce, affected versions or commits, and impact if you can. Maintainers will acknowledge receipt as soon as practical.

This project calls the public [Open-Meteo](https://open-meteo.com/) HTTP APIs over TLS. Reports about third-party API behavior should go to the upstream provider when appropriate.
